# Тестове завдання: детекція птахів на відео


## Мета проєкту

Навчити модель **YOLO26n** для виявлення птахів на зображеннях і відео. Реалізувати процес донавчання моделі, інференс на відеофайлах і збереження результатів обробки.

## Завдання

### 1. Підготовка датасету

- Знайти невеликий відкритий датасет із розміченими зображеннями птахів або самостійно зібрати невелику вибірку.
- Буде також датасет для бінарної класифікації (0 - пташка, 1 - не пташка (природа, авто, людина))
- Привести анотації до формату YOLO.
- Розділити датасет на вибірки `train` і `validation`.
- Підготувати конфігураційний файл датасету.

### 2. Навчання моделі

- Використати попередньо навчену модель **YOLO26n**.
- Донавчити модель для одного класу — `bird`.
- Винести процес навчання в окремий скрипт `train.py`.
- Зберегти найкращі ваги навченої моделі у файл `weights/best.pt`.

### 3. Інференс на відео

Реалізувати скрипт `predict_video.py`, який:

- Приймає шлях до вхідного відеофайлу.
- Запускає модель на кожному кадрі відео.
- Виявляє птахів і відображає для кожного об'єкта:
  - bounding box;
  - назву класу;
  - значення confidence.
- Зберігає оброблене відео у вихідний файл.

### 4. Приклади роботи

- Зберегти найкращі ваги навченої моделі.
- Додати приклад вхідного відео.
- Додати відповідне оброблене відео з результатами детекції.

## Очікувана структура проєкту

```text
bird-detector/
├── README.md
├── requirements.txt
├── train.py
├── predict_video.py
├── data.yaml
├── weights/
│   └── best.pt
└── examples/
    ├── input.mp4
    └── output.mp4
```

`data.yaml` використовується для конфігурації датасету. За потреби можна додати окрему директорію `dataset/` із зображеннями та анотаціями.

README має містити:

1. **Встановлення залежностей** — інструкцію зі створення середовища та встановлення пакетів.

## Приклади запуску

### Встановлення залежностей

```bash
pip install -r requirements.txt
```

### Навчання моделі

```bash
python train.py
```

### Обробка відео

```bash
python predict_video.py --input examples/input.mp4 --output examples/output.mp4
```

Скрипт має зчитувати вхідне відео, виконувати детекцію на кадрах і зберігати результат у вказаний вихідний файл.
